# 焐心小镇 · 玩法设计（赛博小镇 demo 的游戏目标层）

> 在 [agent_world](../agent_world/) 引擎 + 活体世界骨架之上，加一层「社交人情养成」玩法。
> 经 understand→design 两轮 workflow（9 份评审）锁定，**零内核改动、全软引导**。
> 实现落在 `cyber_town/backend/`（装配/薄层/提示词）+ `cyber_town/frontend_web/`（表现），
> 不碰 `agent_world/`。

## 核心幻想

你是新来的农场主。小镇有真实昼夜作息，三位街坊各有各的日子和心事。你掐着点儿出现在
对的地方，递一份心意、搭一把手、把一个人的话带给另一个人——看着这个对你客客气气的
小镇，一点点把你当成自家人。

**独特卖点**：NPC 是 LLM 自主体——会记恩记仇、自主行动/沉默、涌现叙事。所有「好玩点」
都依赖 LLM 自主演出，规则 NPC 做不到。

## 核心循环

看时辰找人（HUD 时辰牌＋街坊去向卡）→ 串门搭话（走进地点／走近按 E）→ 递善意
（送心意／搭把手／带话／群里吆喝）→ 看反应（NPC 自主领情、记住、好感涨落、反过来找你）
→ 小镇升温（好感跨档里程碑＋口碑在街坊间流动）。

## 五个支柱

| # | 支柱 | 怎么实现（落点） | 守红线 |
|---|---|---|---|
| 1 | **焐心曲线**：好感即归属，五档升温＋跨档里程碑 toast | 复用现成好感薄层 `affinity/`；前端 `ws.ts::detectWarmth` 跨档检测 → `Toasts` | 好感 100% LLM 自主 `adjust_affinity`，无规则衰减 |
| 2 | **真实作息·掐时辰找人**：晨/午/暮/夜，NPC 自主按性格去留 | `config.day_phase` 单一真相源；`observation` 时间行注时段事实；`world_director` 时段感事件；前端 `Hud` 时辰牌＋去向卡＋`Scene` 日夜光照 | 时段只作为**事实**注入，去不去全凭 NPC 的 `request_move` |
| 3 | **心意与搭把手**：对象专属礼物/帮忙，NPC 自主领情 | `interactions/gift_help.py` 把 `give_gift/lend_a_hand` 翻译成 F2F `speak_to_local`；`ws_hub` 拦截入队；前端 `PhoneMenu` 当面说页 `GiftBar`（仅同地点开放） | 不新增引擎动词；**绝不后端代加好感**，NPC 像对任何话一样自主领情 |
| 4 | **街坊会记事·口碑流动**：你的好被街坊互相传开 | 近乎零新代码——NPC↔NPC 好感矩阵＋群聊 GRP100＋`prompts/affinity.REPUTATION_NOTE` 软引导；前端 `Hud::RumorFeed` 筛群聊摘「街坊传闻」 | 传不传/对谁传/说多说少全凭 LLM 性格与心境 |
| 5 | **闲聊里长出的托付＋终局接纳** | 软引导（无任务面板）；`snapshot.daily_digest` 跨时段「小镇纪事」只读聚合；三人皆挚友→`world_director._maybe_finale` 投放 `FINALE_FACT` 接风软推力 | 纪事零强制行为；终局只陈述氛围事实，是否张罗全由 NPC 涌现 |

## 进度轴 + 终局

- **人心线**：三位 NPC 对玩家好感（0-100，五档）→ HUD「小镇人情温度」进度条（三人均值）。
- **日子线**：连续天数 + 每跨时段一页「小镇纪事」（好感增量＋来访街坊）。
- **终局**（非硬胜负、会话级）：三人都焐到「挚友」(≥80) → WorldDirector 投放一次接风氛围事实，
  三位邻居**自主**张罗接风。**无 Game Over**——失败＝焐得慢，冷落/敷衍会让好感停滞甚至回落
  （NPC 自评，非规则衰减）。

## 关键工程裁决（评审验证源码后一致砍掉）

- **不接 ScriptEngine**：其 `dialogue_injection` 调 `CyberTownNPC` 没有的 `update_memory()` 会崩、
  `broadcast_event` 写 `direct_message` 字段不符且 `delivered=0` 被静默丢弃。所有「投放事实」走
  现成 `world_event_provider`（第 7 段提示词）。`world_factory` 里 `script_engine=None` 保持不动。
- **不加私有工具台账**（心事/委托落库）：`prompt_suffix_provider`/`private_tool_handler`/
  `world_event_provider` 都是 NPC 上**单个 Optional 槽位**，已被 AffinityManager 与 WorldDirector
  独占；新增全挂现成槽位扩展或走纯前端/纯命令通道，规避「单槽覆盖」。委托完成靠对话涌现，不落库。
- **送礼=玩家命令翻译成 `speak_to_local`**：玩家白名单（`player_agent._ALLOWED_ACTIONS`）已含，
  无需新增引擎动词、不改 dispatcher。礼物目录服务端唯一定义、经 hello 下发前端（三方对齐）。

## 6. 扩充 agent 行为（让世界更活、行为选择更多）

> 第二轮：调研引擎「已存在但 demo 没用」的原生动词 + 没用上的 76 个动画，给
> agent **更多可做的事**。**关键实测结论**：deepseek-v4-flash 只会用「沟通 + 状态」
> 类工具（说话/私信/群聊/调好感/移动/改状态），**基本不碰「结构/元」类工具**
> （结好友/建群/加群/八卦——好感拉满到 100 也 0 次触发）。故凡需 NPC 自主调这类
> 工具的玩法，一律**改为系统派生 / 沿用已生效的涌现**，并删掉不触发的死工具
> （守「不留无用代码」）。最终落地两项新行为 + 一项派生：

| 行为 | 谁用 | 怎么实现（落点） | 守红线 |
|---|---|---|---|
| **活动动画** | NPC | `config.classify_activity` 把 NPC 自写的 current_state 按关键词归到 work/sit/lie/cheer/idle（snapshot `activity` 字段）；前端 `Character.tsx` CLIP 表扩到 KayKit 现成 clip、`Agent.tsx` 据此选动画。NPC 不说话也看着在耕作/歇脚/喝彩 | 纯表现层派生，干啥活仍由 NPC 自写 state 决定 |
| **陪伴互动** | 玩家 | `gift_help.py` 加第三类 `companions`（陪喝一杯/听唠叨/蹲田埂），`spend_time` 命令→翻译成 F2F speak_to_local；前端 GiftMenu 三类（🎁送/💪帮/🍵陪） | 同送礼：翻译成白名单动作、NPC 自主领情 |
| **好友/心结（派生）** | — | `agents/bonds.bond_from_score`：好感 ≥75 自动「好友」、≤8「心结」——与 5 档等级一样是对【LLM 自主好感分】的纯展示派生。渲进第 6 段影响语气、随快照下发前端显示 + 跨阈值弹里程碑 toast | 不新增规则/不指挥行为/不动关系图；私聊可达性始终由 neighbor 提供，永不被锁 |

**已评估后明确不做 / 删除的（实测不触发或重踩旧坑）**：
- NPC `relation_change` 工具 / `share_gossip` 八卦工具 / `create·join·leave_group` 动态群工具
  / PrivateToolRouter / GossipManager —— deepseek-v4-flash 基本不调用，挂着只是死重 + 稀释
  核心社交工具，已全部删除。口碑流动沿用已生效的**涌现版**（支柱4，NPC 经正常 speak/群聊
  自然传开）；群聊保留全员**镇民群**（已验证热闹），不做动态建群（NPC 不会自主加群→会变空群）。
- `capability_change`（NPC 自我失能=收不到私信，重踩 W7/W8「私信必回」坑）——不给 NPC。

工具集回归精简（沟通/状态/好感为主），经回归验证核心行为不被稀释：私信必回、送礼/陪伴
升温、活动动画、好感派生羁绊（大山好感 80→好友、老钱 5→心结）均实测正常。
