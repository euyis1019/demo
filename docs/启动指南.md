# 赛博小镇 demo —— 启动指南

> 星露谷式农场小镇「活体世界」demo：agent_world 引擎 + FastAPI/WebSocket 后端 +
> Godot 4 全代码前端（Web 导出）。仅 PC 端单人。

## 前置条件（首次）

```bash
cd /Users/dawson/Documents/GitHub/demo-cyber-town

# 1. LLM key：写入 backend/.env（已 gitignore，不提交）
echo 'LLM_API_KEY=sk-...' > cyber_town/backend/.env
```

- LLM 网关：DeepSeek 官方 `https://api.deepseek.com`，模型 `deepseek-v4-flash`。
- 无需 `pip install -e .`（vendor/oasis 缺失，按红线用自包含路径直接跑）。

## 前端：默认是真 3D 版（frontend_web，Three.js/R3F）

```bash
# 首次/改前端后需出包（dist 不入库）
cd cyber_town/frontend_web
npm install      # 首次
npm run build    # 出 dist（base 已设 /game/）
```

## 一键启动（最常用）

```bash
cd /Users/dawson/Documents/GitHub/demo-cyber-town
uvicorn cyber_town.backend.main:app --port 8000
```

后端自动托管前端，浏览器打开 **http://127.0.0.1:8000/game/**

> 默认托管**真 3D 版**（`frontend_web`，KayKit GLTF 模型 + PBR + 阴影）。切换：
> - `CYBER_TOWN_FRONTEND=2d ...` → Godot 2D 版
> - `CYBER_TOWN_FRONTEND=godot3d ...` → Godot 伪 3D 版

### 前端开发热重载（改 R3F 代码时更快）

```bash
# 终端1：后端（真 LLM 需 .env，或 CYBER_TOWN_MOCK=1 离线）
uvicorn cyber_town.backend.main:app --port 8000
# 终端2：Vite dev（已配 /ws、/healthz、/agents 代理到 8000）
cd cyber_town/frontend_web && npm run dev
# 浏览器开 http://localhost:5173/game/
```

### 游戏操作

- `WASD` / 方向键：走动；走进区域自动跨地点
- 走近 NPC 按 `E`：直达私聊页
- `Tab`：打开「小镇通」菜单（当面说 F2F / 私聊 RDC / 群聊 GRP）
- 点击 NPC：查看其行为档案（时间轴）

## 可选开关（环境变量）

```bash
# 离线 Mock 模式：不调 LLM、零网络，纯调试画面/协议
CYBER_TOWN_MOCK=1 uvicorn cyber_town.backend.main:app --port 8000

# 关闭管理类 agent：回退「全员每拍激活、无环境事件」
CYBER_TOWN_DIRECTORS=0 uvicorn cyber_town.backend.main:app --port 8000

# 自定义心跳间隔（秒/拍，默认 2.5；调试可调快）
CYBER_TOWN_TICK_SECONDS=1.0 uvicorn cyber_town.backend.main:app --port 8000
```

可组合，例如 Mock + 快心跳：

```bash
CYBER_TOWN_MOCK=1 CYBER_TOWN_TICK_SECONDS=0.5 \
  uvicorn cyber_town.backend.main:app --port 8000
```

## 改了前端脚本后：重新导出 Web 包

改了前端 `.gd` 后浏览器版不会自动更新，需重新导出（需 Godot 4.6 + Web export templates）。
**默认前端是 3D 版 `frontend3d`**：

```bash
cd /Users/dawson/Documents/GitHub/demo-cyber-town

# 改了图片/新增资源时，先重新导入
godot --headless --path "$PWD/cyber_town/frontend3d" --import

# 导出 Web 包到 dist/（后端从这里托管）
godot --headless --path "$PWD/cyber_town/frontend3d" \
  --export-release "Web" "$PWD/cyber_town/frontend3d/dist/index.html"
```

> 2D 版同理，把上面的 `frontend3d` 换成 `frontend`，并用 `CYBER_TOWN_FRONTEND=2d` 启动后端。

导出完成后刷新浏览器即可（首次加载 WASM 约 30 秒）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动报「未找到 LLM key」 | 检查 `cyber_town/backend/.env` 是否有 `LLM_API_KEY=...` |
| 浏览器停在 Godot 加载页 | WASM 编译慢，等约 30 秒；仍不动则看后端日志有无报错 |
| 改了 `.gd` 没生效 | 需重新导出 Web 包（见上节）；纯改后端无需导出 |
| 想快速验证画面 | 用 `CYBER_TOWN_MOCK=1` 离线起服，不消耗 LLM |
| 端口被占 | 换 `--port`，对应浏览器地址同步改端口 |
