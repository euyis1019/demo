# 真 3D Web 前端方案（换栈：Godot → Three.js / React-Three-Fiber）

> 背景：Godot 4 Web 导出只能用 **Compatibility/WebGL2** 渲染器（实时阴影/多项 3D 特性缺失），
> 加上像素 billboard 伪 3D，**材质上限被引擎硬卡死**——这是「材质没变化、不可用」的根因，
> 不是参数问题。且首包是 36MB wasm（9MB gzip）。结论：换 **Web 原生 3D 引擎 + 真 3D 模型**。
>
> **后端零改动**：FastAPI + WebSocket `/ws/world` + JSON 协议与 `agent_world` 引擎全部保留；
> 废弃的只是 Godot 前端（`frontend/`、`frontend3d/`）。

## 1. 选定栈：Three.js + React-Three-Fiber + drei + zustand + Vite/TS

- `three` + `@react-three/fiber`(R3F) + `@react-three/drei` + `@react-three/postprocessing`，
  状态 `zustand`，脚手架 `Vite + React18 + TS(SWC)`。
- **为何胜过 Godot**：R3F 是纯前端 JS，`MeshStandardMaterial` 原生 **PBR**、drei `<Environment>`
  一行 IBL/HDRI、PCFSoft 实时阴影、后处理 Bloom/SSAO 全可用；首包 three 核心 ~168kB gzip、
  模型按需流式（目标首包 JS <1MB + 模型 <10MB，对比 Godot 40MB 是**数量级改善**）；
  AI 协作语料量碾压（three 周下载 ~500 万 vs Babylon/PlayCanvas ~1–1.5 万），最好开发。
- 为何不是 Babylon（包大、React 集成生硬、语料少）/ PlayCanvas（强在云编辑器+移动端，
  本项目 PC 单人代码型用不上）。
- 脚手架：`npm create vite@latest frontend_web -- --template react-swc-ts`；
  `npm i three @react-three/fiber @react-three/drei @react-three/postprocessing zustand`。

## 2. 资产（全 CC0、glTF，可商用免署名）

- **角色（玩家+3 NPC）**：[KayKit Adventurers](https://kaylousberg.com/game-assets/characters-adventurers)
  ——已绑骨已动画低多边形角色，~75 动画（idle/walk/talk）+ 配件，免费档 5 个角色正好覆盖
  玩家+3 村民+备用，**无需自己绑骨**。按现有 `config.gd::CHARS` 对位：0 玩家/1 老钱/2 阿香/3 大山，
  换配件+主色区分。
- **环境/建筑**：[Kenney Nature Kit](https://kenney.nl/assets/nature-kit)(≈330) + Survival Kit +
  Building/City Kit；[Quaternius LowPoly Nature](https://quaternius.itch.io/150-lowpoly-nature-models)；
  酒馆室内用同作者 KayKit Restaurant/Furniture Bits（与角色共用渐变 atlas 保风格统一）。
  批量下载走 [Poly Pizza](https://poly.pizza/bundles)。
- **风格统一**：尽量同作者 + 同一套光照(单 DirectionalLight+HDRI)+ 统一 toneMapping。
- **压体积（必做）**：`gltf-transform` / `gltfpack` 走一遍——几何 Meshopt/Draco(~10x)、
  贴图转 **KTX2/BasisU**（省显存）、合并降 draw call。整镇通常压到个位数 MB。

## 3. 工程架构（`cyber_town/frontend_web/`，与 frontend3d 并列）

```
src/
  net/      ws.ts（WS 单例+0.3s 节流+指数退避重连）  protocol.ts（按 snapshot.py 1:1 写 interface）
  store/    worldStore.ts（zustand：agents/places/playerView/worldTime/worldEvent/contacts/connected + helloMeta）
  scene/    Scene.tsx(<Canvas>)  Ground.tsx  Place.tsx  Agent.tsx(GLTF+动画状态机)  Player.tsx  CameraRig.tsx  Bubble.tsx
  ui/       PhoneMenu.tsx  ChatPanel.tsx  ContactList.tsx  Hud.tsx（React DOM 覆盖 Canvas）
  assets/   *.glb(KTX2)
```

- **数据流铁律**：WS 收 snapshot → `useWorldStore.setState()` 切片；Agent 组件按 id selector 只订自己那份
  （别把整 snapshot 塞 React state）；`useFrame` 读 store 对位置 **lerp 插值**（每拍 2.5s，否则瞬移）。
- **snapshot→场景映射**：复用 `config.gd` 世界常量换 `Vector3(x,0,z)`——三地块横排
  farm(x=-28)/square(0)/saloon(28)，`PLACE_RECTS`/`ANCHORS` 照搬；`location`→锚点轮用。
- **NPC 动画状态机**（drei `useGLTF`+`useAnimations`）：移动→walk+lerp、到位→idle、`bubble` 非空→talk，
  `fadeIn/fadeOut(0.2)` 交叉淡入。**多实例蒙皮模型必须 `SkeletonUtils.clone`**（R3F 已知坑）。
- **相机**：drei `<OrthographicCamera>`（复刻星露谷俯视，CAM_SIZE≈13）跟随玩家。
- **玩家**：WASD 运动学 + 地块矩形判定，走进区域（内缩矩形滞后）→自动发 `request_move`。
- **对话气泡/名牌**：drei `<Html>`（真 DOM，**中文最清晰**，4 个 agent 无性能压力）。
- **手机菜单/聊天**：React DOM 重写——换栈最大白捡收益（表单/滚动/中文输入法远比 Godot 好写）。

## 4. 连后端 + 托管（后端零改动）

- 协议照搬 `world_net.gd`：下行 `hello_ack/snapshot/ack/error`；上行 `{action,client_seq,kwargs}`，
  命令白名单仅 5 个（speak_to_local/send_message/send_to_group/request_move/do_nothing）。
- **开发**：终端1 `uvicorn ...:app --port 8000`（或 `CYBER_TOWN_MOCK=1` 离线）；终端2 `npm run dev`；
  `vite.config.ts` 配 `server.proxy` 把 `/ws`(开 `ws:true`)、`/healthz`、`/agents` 代理到 8000。
- **托管**：`vite build` 出 dist；FastAPI 同源托管（`main.py` 的 `CYBER_TOWN_FRONTEND` 多认一个 `web` 值，
  1 行装配层改动；或直接覆盖到 frontend3d/dist 实现零改动）。**坑**：挂在 `/game/` 子路径，
  `vite.config.ts` 必须设 `base:'/game/'` 否则资源 404。

## 6. 风险与对策

1. 首屏臃肿 → gltf-transform 离线压 + Suspense/`<Loader>` 进度条；解码器放 public。
2. 多 NPC 共用骨骼 clone 崩骨架 → **`SkeletonUtils.clone(scene)`**（非 `scene.clone()`）。
3. 位置瞬移 → `useFrame` lerp 插值（每拍 2.5s）。
4. 动画手感（最需迭代）→ `useAnimations` 交叉淡入，walk/idle/talk 由 snapshot.moves/bubble 驱动。
5. 地块边界抖动反复 request_move → 内缩矩形滞后 + pending 期置灰「当面说」。
6. 命令丢失 → 复刻 0.3s per-action 节流 + UI 乐观上屏、NPC 回复等下一帧。
7. 实时阴影贵 → 静态小镇烘焙、实时阴影只给玩家/NPC、用 DirectionalLight(1 draw call)。
8. CJK 文字 → 用 `<Html>`(吃系统中文字体) 而非 `<Text>`(需 CJK 字体 atlas)。

## 7. 保留 / 废弃 / 新增

- **保留（一行不动）**：`cyber_town/backend/` 全部、WS 协议、`world_seed/scenario.yaml`、`agent_world/` 内核。
- **废弃**：`cyber_town/frontend/`、`cyber_town/frontend3d/`（Godot + GDScript + 2D 像素 billboard + 36MB wasm）。
  现有 GDScript 里的交互规则（地块/锚点/相机/气泡/手机菜单/E 直达私聊/重连/节流）**换算成 TS 保留**，不重新设计。
- **新增**：`cyber_town/frontend_web/`（R3F 真 3D）。
